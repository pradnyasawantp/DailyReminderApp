# Daily Reminder

Daily Reminder is a simple Android application for creating general-purpose reminders for everyday tasks, events, routines, and activities.

Users can create a reminder with a title, choose a time, select one or more repeat days, and receive a local notification when the reminder is due.

## Features

- Create generic reminders
- Choose a time
- Repeat on selected days
- Edit reminders
- Delete reminders with confirmation
- Local scheduled notifications
- Restore scheduled reminders after device reboot
- Dismiss a reminder from the notification or reminder screen

## Scope

The application is a general-purpose reminder utility. It does not provide medication management, dosage tracking, prescription management, treatment planning, medication adherence tracking, medical advice, or health-data storage.
